## Verification

After the application metadata is set to 1.8.2, run from your actual project folder:

```bash
node scripts/verify-presentations.cjs
node --test scripts/test-presentation-persistence.cjs
npm start
```

The updated verifier expects v1.8.2 application metadata and the new release-document hashes. For `app.js` it accepts the previously supplied presentation renderer or the exact same renderer with only its About label changed to v1.8.2. Arbitrary runtime changes are not exempted from hashing. The other version-label files are outside this focused presentation manifest; verify their targeted edits before packaging.

No dependency installation is needed solely for these documentation/verifier changes. Older unrelated version-specific verifiers may still describe earlier source revisions; this update does not rewrite every historical patch manifest.
